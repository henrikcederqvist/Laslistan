# User Stories – Läslistan

Webbsidan har fyra vyer: **Katalog**, **Lägg till bok**, **Mina böcker** och **Statistik**.

---

## Navigering

**US-NAV-1**
> Som användare vill jag kunna navigera mellan alla vyer via en meny,
> så att jag enkelt kan hitta det jag letar efter.

---

## Katalog

**US-KAT-1**
> Som användare vill jag se en lista med alla böcker i katalogen,
> så att jag kan bläddra bland tillgängliga titlar.

**US-KAT-2**
> Som användare vill jag se varje boks titel och författare,
> så att jag vet vad böckerna handlar om och vem som skrivit dem.

**US-KAT-3**
> Som användare vill jag kunna markera en bok som favorit,
> så att jag kan spara böcker jag är intresserad av.

**US-KAT-4**
> Som användare vill jag kunna ta bort favoritmarkeringen från en bok,
> så att jag kan hålla min favoritlista aktuell.

---

## Lägg till bok

**US-ADD-1**
> Som användare vill jag kunna lägga till en ny bok med titel och författare,
> så att katalogen kan utökas med böcker som saknas.

**US-ADD-2**
> Som användare vill jag se ett bekräftelsesmeddelande eller att boken dyker upp i katalogen efter att jag lagt till den,
> så att jag vet att åtgärden lyckades.

**US-ADD-3**
> Som användare vill jag inte kunna skicka in ett tomt formulär,
> så att katalogen inte fylls med ogiltiga poster.

---

## Mina böcker

**US-FAV-1**
> Som användare vill jag se en lista med alla mina favoritmarkerade böcker,
> så att jag snabbt hittar böckerna jag sparat.

**US-FAV-2**
> Som användare vill jag kunna ta bort en bok från mina favoriter direkt i vyn Mina böcker,
> så att jag slipper navigera tillbaka till katalogen.

**US-FAV-3**
> Som användare vill jag se ett meddelande om listan är tom,
> så att jag förstår att inga böcker är markerade som favoriter.

---

## Statistik

**US-STAT-1**
> Som användare vill jag se det totala antalet böcker i katalogen,
> så att jag får en överblick över katalogens storlek.

**US-STAT-2**
> Som användare vill jag se hur många böcker jag har markerat som favoriter,
> så att jag vet hur stor min läslista är.

**US-STAT-3**
> Som användare vill jag att statistiken uppdateras direkt när jag lägger till en bok eller ändrar en favorit,
> så att siffrorna alltid stämmer med det faktiska innehållet.
